# laptop; main's CI tests everything after the merge. This file is their one definition.
# Lines: `<set> sbt <command>` (a set's sbt lines go to sbt in order: the basic ones inside the `sbt` check's run, an
# area's in one scripts/sbt-warm call), `<set> sh <command>` (run by bash from the checkout's root, after the set's
# sbt lines) or `<set> first <command>` (an area's: run by bash from the checkout's root BEFORE its sbt lines and their
# test-impact selection; a failure fails the area there, its output shown, nothing else run). Blank and # lines are
# skipped. Sets:
#   basic     rides the hook's `sbt` check, whenever that runs. Deterministic, self-contained, seconds to a few minutes

#             infra/bin/fetch-gitops has fetched them). The generated-artefacts drift is the path-selected `drift` check.
#   fast      what `pre-push --fast-only` runs in place of `basic`: the `waiting` batch's combined check at green, after
#             every change in it passed its own full checks (the owner, 2026-10-27: "when waiting is rebuilt, just run very
#             basic checks like compile and the fast tests"). Every test config compiled, the lint and structure specs;
#             target 3 min warm. No area tests.

#             the change can reach, over the countries it can reach (scripts/ci/identity_impact.py: the hook's
#             select_identity_tests), each class once; every line when the change reaches the build or an unknown reader
#   page      the `page` check, on a change to the hook's page paths (is_page_path)
